## Why These Sites Are Difficult to Scrape

The sites you mentioned (JTZ MAG, Ugaflix, UGMovieBox, PearlPix, TulaWatch) all use:
- **JavaScript-heavy rendering** (React/Next.js/Vue)
- **Lazy loading** (content loads as you scroll)
- **Anti-scraping measures**
- **Dynamic URLs**

### What This Means:
Simple HTTP requests don't work because the HTML is generated by JavaScript in the browser.

## Solutions Going Forward

### Option 1: Manual Catalog Updates (Current)
- I've added 12 sample movies from TulaWatch
- You can manually add more movies to `public/narabox_catalog.json`
- Format:
```json
{
  "title": "Movie Name",
  "vj": "VJ Name",
  "slug": "movie-name-vj-name",
  "url": "https://site.com/movie/link",
  "poster": null,
  "overview": "Description here",
  "source": "TulaWatch"
}
```

### Option 2: Browser Automation (Advanced)
Requires Puppeteer or Playwright to render JavaScript:
```bash
npm install puppeteer
```
Then create scraper that opens browser and extracts content.
