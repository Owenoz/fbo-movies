## Adding More Movies Manually

If you find movies on other sites, you can add them manually:

```bash
nano public/narabox_catalog.json
```

Format:
```json
{
  "title": "Movie Title",
  "vj": "VJ Name",
  "slug": "movie-title-vj-name",
  "url": "https://site.com/movie",
  "mp4": "https://cdn.com/video.mp4",
  "poster": "https://image.com/poster.jpg",
  "overview": "Movie description here"
}
```
